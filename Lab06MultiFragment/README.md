# 实验六 多 Fragment 应用

罗元 2024110827。基于实验五 Dev 分支的 RecyclerView 牌面、计分和重开逻辑。

在 Android Studio 打开本目录，选择 Android 模拟器，运行 app。

- 资料页支持保存姓名、学号、电话、邮箱、性别与爱好，并显示历史最高分。
- 两张牌模式使用 16 张牌，三张牌模式使用 24 张牌。横竖屏调整列数并保留当前牌局。
- 三个页面使用不同的应用私有存档。保存资料、翻牌或重开后会写入存档，退出进程后再打开可恢复内容。
- 单元测试覆盖两种配对规则。界面测试验证页面切换及 Activity 重建后的 Fragment 恢复。通过强制停止并重新启动验证资料与独立牌局的持久化。

实验报告和实测截图见本目录的 docs 文件夹。
